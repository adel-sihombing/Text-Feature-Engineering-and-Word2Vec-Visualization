# TEXT PROCESSING - Text Feature Engineering & Word2Vec

This project explores text processing and feature engineering techniques using Python. It covers One-Hot Encoding, Bag of Words, and TF-IDF to represent text data, as well as tokenization using NLTK to split text into individual words.

The project also implements Word2Vec using Gensim to generate 100-dimensional word embeddings with the CBOW architecture. The resulting word vectors are visualized in two dimensions using UMAP and Plotly to help illustrate the relationships between word embeddings.

## Requirements

This project uses Python 3.11 or later and can be run in Google Colab or Jupyter Notebook. The required libraries include pandas, scikit-learn, requests, beautifulsoup4, nltk, gensim, numpy, umap-learn, and plotly.
